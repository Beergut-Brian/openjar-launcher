Shared addon consumed by every game as a pinned submodule. Read `README.md`.

- Godot 4.x syntax only (see the template's CLAUDE.md for the do/don't list). Pinned 4.7.2.

- Keep `plugin.cfg` version in sync with the tag.
- Branch per change, PR to `main`. The maker profile merges.
