## The one check no palette can pass

Player green `#3CC24A` and player red `#E4393C` are 75.8 apart (CIEDE2000) for normal vision, but only **9.5** apart under a Machado 2009 deuteranopia simulation (severity 1.0, linear RGB). The target is 20. Both are fixed colours, so nothing in the surrounding palette can change this number; every candidate fails this one row for the same reason.

What still separates P1 and P2 for a red-green colour-blind viewer: lightness (green is much lighter, which survives the simulation) and the characters themselves (round yellow hood and comb vs. flat dark hat). If Kaden wants the number to pass, the smallest single changes found by search are:

- player red `#E4393C` → `#BA272A` (shift ΔE 10.1, deuteranopia gap becomes 20.2)
- player green `#3CC24A` → `#66EC6E` (shift ΔE 10.4, deuteranopia gap becomes 20.0)

Not applied. This is Kaden's call.

## Notes on the rules

- Ink contrast: every colour except the ink itself is tested against the ink at WCAG 3:1. The two near-black fixed colours (hat, shirt) cannot reach 3:1 against any near-black outline, so they are drawn with an inner rim line in the palette's *stone* colour and tested against that instead.
- The ink has to be very dark (relative luminance ≤ 0.0036) because jeans blue `#3B5BA5` is itself fairly dark; that is why all three inks are near-black and only differ in tint.
- Sky tiers get darker every step (L* falls), so the order reads at a glance. 'Cloud deck' is the sky colour at cloud height; the clouds themselves use the light neutral.
- Jeff's comb uses the palette's comb colour, not player red, as his look sheet asks.
- Skin is not really a master-palette job: each palette's *clay* doubles as a skin placeholder on the mock cards; real skin tones come from the character library.

## Recommendation

**C, Cool Arcade**: its closest call between a player colour and any sky tier or soil ring is ΔE 29.6, against 27.0 for A and 25.3 for B, so P1 green and P2 red pop hardest on the TV in every game.
